# Security Policy

## Supported Versions

Always use the most recent release version. No security updates will be provided for outdated releases.

## Reporting a Vulnerability

If you identify a vulnerability, please email [Xerolux](mailto:git@xerolux.de) before making it public, to allow time to address and fix the issue.

## Optional cloud AI reports

Plant communication and control remain local. Experimental cloud reports require explicit consent and a provider-specific API key. Keys are redacted in integration diagnostics but stored in HA configuration and backups; protect them accordingly. See [AI privacy and limits](wiki/Experimental-AI-Adviser.md#optional-cloud-reports-v0172-b10). Cloud processing is optional and never enables control tools.
