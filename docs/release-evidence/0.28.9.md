# Release evidence for 0.28.9

The maintainer requested a stable patch for two read-only web counters. The Navigator 10 regression replays a 28,965.97 kWh lifetime reading against a valid 28,826.14 kWh baseline and checks the daily reset and subsequent progress. The runtime regression replays a negative reading between valid samples. The issue reports contain sensor history rather than raw frames from the incidents. Field confirmation is pending for both.

On Home Assistant 2026.11.0 the integration passed both coverage gates (96.42% overall and 100% for the config flow) and all 16 real-Home-Assistant tests. On 2026.12.0b2, commit `68a5f4a` passed 3,769 unit tests, all 16 lifecycle and service tests, strict mypy and a loopback FC04 read through the shared Modbus provider. Two POSIX-only release tests were skipped on Windows. The minimum supported Home Assistant remains 2026.11.0 and the API pin remains 2.18.0.
