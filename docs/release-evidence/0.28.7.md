# Release evidence for 0.28.7

In [issue #719](https://github.com/Xerolux/idm-heatpump-hass/issues/719), the reporter confirmed that 0.28.6 restored the previous setpoint on a Navigator 10. The charge resumed when the controller returned from standby to automatic.

The Home Assistant 2026.11.0 service test starts a boost at 60 °C from 52 °C, cancels once and lets the write interval expire on a simulated controller. It checks the register writes for the raised setpoint, the one-time demand, the restored setpoint and the withdrawal. Additional tests cover requests already active at startup, loss of ownership during recovery, storage failures, stale data, timeout handling and PV cooldown.

The release retains API 2.17.0 and the transport minimum supported by Home Assistant 2026.11.0. The built-in Modbus integration pins 4.12.7 there and 4.12.8 on Home Assistant 2026.11.3. The release check verifies both constraints. [Home Assistant 2026.11.0 manifest](https://github.com/home-assistant/core/blob/2026.11.0/homeassistant/components/modbus/manifest.json) · [Home Assistant 2026.11.3 manifest](https://github.com/home-assistant/core/blob/2026.11.3/homeassistant/components/modbus/manifest.json)

This is a same-day patch. A seven-day observation period and a test of the standby-to-automatic transition on the reporting Navigator 10 remain open.
