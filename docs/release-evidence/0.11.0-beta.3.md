## Change vs 0.11.0-beta.2

- Transient Modbus exception codes 5/6/10/11 are now translated to
  `ModbusException` (retry-in-place path per the API 1.0 transport contract)
  instead of `ModbusIOException`, which would have forced the API's hard
  reconnect path. `IllegalAddressError` for code 2 (coordinator bisect) is
  unchanged.
- Removed the unused `_NON_RETRYABLE_DEVICE_EXCEPTION_CODES` set and corrected
  comments that misdescribed the API retry behavior.
- No register map, entity set, config-flow or service changes.
