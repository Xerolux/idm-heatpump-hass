# 0.23.2-b4 validation evidence

Date: 2026-10-26. This beta ships the Navigator 10 dual-label sensor fix from
issue #598 (field report: on an AERO ALM 6–15 with Navigator 10 and a
separation heat exchanger, the intermediate-circuit flow/return entities
vanished on 0.23.2-b2/b3 whenever a Modbus connection was active). The API pin
is unchanged at `idm-heatpump-api[web]==2.14.5b2`; the integration overrides
the library's `B33/B113`/`B34/B114` sensor-name mapping with dedicated
intermediate-circuit value keys, because `setdefault` could not replace the
library's own `flow_temperature` mapping that 2.14.5b2 introduced. The same
release ignores the DTZ lint rules a new ruff release activated; the naive
wall-clock datetimes in the technician-code paths are deliberate.

## Reproducible dependency pair

- Integration: `0.23.2-b4`.
- API: `idm-heatpump-api[web]==2.14.5b2` (unchanged from 0.23.2-b3).
- Transport floors: `modbus-connection>=4.12.4`, `tmodbus[async-serial]>=0.6.2`.

## Local validation

- Integration: 3,149 tests passed against the published `2.14.5b2` artifact
  (local venv synced to the exact pin after CI exposed a stale-local-pin gap
  that had let the broken first version of the mapping test pass locally);
  99.82% coverage against a 95% gate.
- Ruff lint/format and strict mypy passed on the integration tree.
- `scripts/check_dependency_pins.py`: `2.14.5b2` is current (no pin change).
- `scripts/check_documentation_versions.py`: current integration and runtime
  versions in registered documentation match the manifest (after `--update`).
- The full CI matrix on pull request #604 passed: both Home Assistant floors,
  manifest-pinned and api-main dependency modes, real-Home-Assistant lifecycle
  smoke tests, hassfest and HACS validation.

## Evidence boundaries

No physical controller was contacted for this release. The fix is verified by
unit and regression tests against fake web frames (mapping override, Modbus
duplicate suppression, register bridging for web-only plants). Field
confirmation of the renamed entities on the reporter's plant is open — issue
#598 stays open until then, as do #577, #493 and the diagnostic-data
collection issue #594.
