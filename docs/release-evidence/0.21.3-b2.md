# Release Candidate Evidence: 0.21.3-b2

Status: `BLOCKED` for stable promotion; automated and targeted field checks passed.

## Scope

Connection failures during writes now use a delivery/connection explanation,
including the configured Modbus proxy path. Actual controller rejections retain
their register-access explanation. The existing scoped repair identity is kept,
and a successful write clears its persisted warning only when the warning names
that same register address. There is no transport, endpoint or write-retry change.

The candidate also adds EN/DE SolarEdge GLT instructions and a standalone
explicit-source template/mapping generator. The generator accesses neither HA
nor hardware, requires both power-sign conventions, rejects duplicate sources
and refuses to overwrite output files. AC/DC and partial-sum limitations and
the lack of a controller-side HA-outage watchdog are stated explicitly.

- Six write-repair regression cases cover connection/transport/timeout errors

- Coordinator suite: 192 tests passed.

- Full unit suite: 2530 passed, two skipped; global coverage 95.06 percent;

- [PR checks](https://github.com/Xerolux/idm-heatpump-hass/pull/496),
  [main CI](https://github.com/Xerolux/idm-heatpump-hass/actions/runs/38284280337),

- Owner-authorized read-only ModBridge verification before this candidate:

## Upgrade and targeted recovery check

HACS installed the exact prerelease from the preceding candidate. HA configuration
validation passed before restart. After restarting, the IDM entry loaded without
an error, and diagnostics confirmed the running candidate and the existing
five-register GLT mapping. The Modbus proxy endpoint and separate Navigator web
endpoint were preserved.

Before the upgrade, the issue registry contained the old scoped `write_rejected`
warning for the surplus register even though ongoing writes were successful.
After the upgrade, the warning cleared automatically through successful GLT
forwarding; it was not manually dismissed. A second issue-registry read after
sampling still showed no IDM write warnings, and diagnostics reported no current
write error.

Twelve additional read-only samples through the configured ModBridge listener
returned all five GLT measurements. Direct Navigator web frames contained a
battery in every sample and SOC stayed valid. This is a short targeted field
check, not a full fresh-configuration smoke test or long-term reliability claim.

The transient connection failure was not reproduced during this observation.
Proxy uptime is not guaranteed by this UI/repair correction. The older #493
controller-display report remains open. Seven consecutive 24-hour soak periods,
complete release smoke evidence and maintainer sign-off remain pending.
