# Release evidence: 0.22.0

Date: 2026-10-15. Scope: the stable cut of the 0.22 line — the seven
prereleases b1–b7 (2026-10-13 through 2026-10-15), which absorbed the
never-promoted 0.21.3 line, folded into the single stable changelog
section; manifest and documentation versions moved to `0.22.0`. No code
changed against 0.22.0-b7; the delta is changelog, manifest version and
version-bearing documentation only.

## Release line summary

- b1: absorbs the 0.21.3 line — #504 fixes (advisor implausible room
  temperatures, HA room-temperature sources, nav20 model correction) and
  the #493 write-cancellation hardening; outage-dampened forwarder
  logging.
- b2: five-minute quiet outage window for connection-class Modbus
  failures (stale snapshot instead of UpdateFailed, no repair, writes
  pause at debug; controller-answered failures still escalate
  immediately).
- b3: GLT RAM refresh at 3 s, write-cooldown cap 2 s for external power
  measurement registers, confirmation-poll bypass, integer battery SoC,
  battery-card hint (#493 live diagnosis).
- b4: restart-safe room/storage/humidity forwarding — the periodic pass
  rewrites unchanged values so controller restarts no longer leave GLT
  sentinels behind (found live on the maintainer's plant).
- b5: bidirectional grid meter input with sign convention; `pv_surplus`
  and `house_consumption` derived from the site balance (#519).
- b6: quantized external power writes — optimistic state equals the
  register readback, `-0.0` normalized (#519 reporter feedback).
- b7: guided options walk reaches the advisor room sources step
  (#527); Configuration wiki note on the HA 2026.8+ gear-icon entry
  point (#526).

## Field soak

The line ran on the maintainer's Navigator 10 plant (HA entry through
the Modbus proxy, web supplement active) from 2026-10-13, including the
recurring proxy outages: the quiet window and dampening were verified
clean there from b1 on (repairs self-clear, no warning spam). External
reporters validated the bidirectional grid meter (#519 confirmed on b5,
rounding follow-up on b6) and drove #493 and #504 with logs; their fixes
shipped inside the line. The unchanged b7 candidate soaked for under a
day before this cut — short of the seven-day gate, and the line's code
changed almost daily. The maintainer decided to cut anyway: the
write-surface changes are confined to GLT RAM inputs (no
EEPROM-sensitive register is touched by any new path; the refresh
cadence is mandatory on the affected firmwares), while the register map,
model-detection core and web supplement are unchanged from the 0.21.x
stable. Issue #493 stays open for the reporter's firmware-specific
battery display flicker — controller-internal, under investigation with
IDM support, no impact on control or data integrity (see the 0.22.0
release decision on the stability page).
