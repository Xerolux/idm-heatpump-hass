# 0.23.2-b2 validation evidence

Date: 2026-10-25. This beta adds recognition for Navigator 10 dual-label sensor
identifiers (B33/B113 and B34/B114) for heat pump installations with an
intermediate heat exchanger (Trennwärmetauscher / frost-protected outdoor loop,
issue #598) and cleans Python 3.14 event loop warnings and quality-scale pins (#599).
It does not claim to fix the remaining Navigator 1.7 web/status issues (#577)
or the recurring battery-display issue (#493).

## Reproducible dependency pair

- Integration: `0.23.2-b2`.
- API: `idm-heatpump-api[web]==2.14.5b1`, published on PyPI after API PR #141.
- Transport floors: `modbus-connection>=4.12.4`, `tmodbus[async-serial]>=0.6.2`.

## Local validation

- API: 613 tests passed in a clean exported tree; 88.03% coverage against a
  75% gate. Ruff lint/format and strict mypy passed.
- Integration: 3,147 tests passed, two skipped; 99.83% coverage against a 95%
  gate. A separate complete run passed with 100% config-flow coverage.
- Real Home Assistant 2026.8.1, Python 3.14.2 and the published API prerelease:
  lifecycle smoke tests passed. Strict mypy passed against that runtime.
- Ruff lint/format, dependency freshness, documentation versions/language and
  the sensitive-data guard passed. The newer transport release remains held at
  Home Assistant's own validated floor.

## Evidence boundaries

Dual-label sensor registration ensures B33/B113 and B34/B114 map to
`flow_temperature` and `return_temperature` respectively, preserving
machine-circuit temperature parity with standard installations and bridging to
Modbus registers 1050 (`hp_flow_temp`) and 1052 (`hp_return_temp`).

Heating circuits HK A–G remain distinct on B51–B57. No physical controller
writes or changes to existing registers were made.
Field confirmation for #598 and requested private capture data for #577 remain
open. The diagnostic-data collection issue #594 remains open.
