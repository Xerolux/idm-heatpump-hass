# Release evidence for 0.28.6

The test models the Navigator 10 quick cancellation reported in [issue #719](https://github.com/Xerolux/idm-heatpump-hass/issues/719#issuecomment-7111052878). It starts a boost at 60 °C from a saved setpoint of 52 °C, presses Cancel once and simulates two EEPROM write refusals. With Home Assistant’s eager task scheduling, 0.28.5 left the setpoint at 60 °C after the write interval elapsed. With the fix, the next eligible coordinator update restored 52 °C exactly once under both eager and deferred scheduling.

The runtime change passed 3,741 unit tests and 15 lifecycle tests on Home Assistant 2026.11.0 with the pinned iDM API 2.17.0. Integration coverage was 98.36% and config flow coverage was 100%. Verification used a simulated controller. Confirmation on the reporting Navigator 10 remains open.
