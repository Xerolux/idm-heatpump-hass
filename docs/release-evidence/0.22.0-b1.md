# Release Candidate Evidence: 0.22.0-b1

Status: `BLOCKED` for stable promotion; automated validation passed. Opens
the 0.22 line on top of 0.21.3-b6.

## Scope

- **Advisor room-temperature sources (added):** one optional, read-only Home
  Assistant temperature sensor per heating circuit, configured in a new
  options step shown when the predictive advisor is explicitly enabled.
  The engine consults the mapped sensor before the register under the same
  0-50 °C plausibility range; the advisor's data quality tracks the mapped
  source under the register's key (unavailable source → unavailable sample);
  `capabilities.room_temperature` reports true with a mapped source. Nothing
  is written to the heat pump (#504 reporter's requested feature).
- **Symmetric web-variant correction (fixed):** a connected nav20 web client
  corrects a Navigator model misdetected as Navigator 10 with the same
  persistence and INFO log as the nav10 path; a web model whose family
  implies a different variant is still ignored (#504 follow-up).
- **Forwarder outage dampening (fixed):** the external power, room
  temperature and humidity forwarders log one WARNING per Modbus connection
  outage and keep retries at debug until a write succeeds — found in the
  maintainer's log, where the GLT refresh cadence repeated the per-register
  delivery warning throughout a proxy-host outage.

No polling, transport, dependency or write-path policy changes beyond the
above. The #493 GLT RAM refresh fix from 0.21.3-b5 remains pending the
reporter's confirmation.
