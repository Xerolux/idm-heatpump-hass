# 0.23.2-b1 validation evidence

Date: 2026-10-24. This beta addresses the Holiday system-mode rejection in #596.
It does not claim to fix the remaining Navigator 1.7 web/status issues (#577)
or the recurring battery-display issue (#493).

## Reproducible dependency pair

- Integration: `0.23.2-b1`.
- API: `idm-heatpump-api[web]==2.14.5b1`, published on PyPI after API PR #141.
- Transport floors: `modbus-connection>=4.12.4`, `tmodbus[async-serial]>=0.6.2`.
- API wheel SHA-256:
  `d3c8dfe331f3db126c6109284942a3cdce11fc05eac5241626133f5311da0922`.
- The downloaded wheel's SHA-256 matches PyPI metadata; all nine Python files
  match API tag `v2.14.5b1` byte for byte.

## Local validation

- API: 612 tests passed in a clean exported tree; 88.03% coverage against a
  75% gate. Ruff lint/format and strict mypy passed.
- Integration: 3,146 tests passed, two skipped; 99.83% coverage against a 95%
  gate. A separate complete run passed with 100% config-flow coverage.
- Real Home Assistant 2026.8.1, Python 3.14.2 and the published API prerelease:
  eight lifecycle smoke tests passed. Strict mypy passed against that runtime.
- Ruff lint/format, dependency freshness, documentation versions/language and
  the sensitive-data guard passed. The newer transport release remains held at
  Home Assistant's own validated floor.
- The full runs exposed a pre-existing PIN mismatch in the capture progress
  fixture. It was corrected afterward, with output moved into a temporary
  directory and an assertion that the WebSocket capture succeeds. The corrected
  test passed with unhandled thread exceptions treated as errors.

## Evidence boundaries

The API tests exercise all six shared-family modes through a simulated Modbus
transport, including exact read/write request shapes, invalid-mode rejection
and retained EEPROM cooldown. Navigator 1.7's mode table stays separate.
Integration contracts ensure the selector's options are accepted by the API.

Forwarding tests confirm that stopping sends no reset values and restarting
uses current source states. They do not establish a universal controller TTL
or explain the reported difference between processed value and GLT input.
No speculative shutdown reset or byte-decoding correction is included.

No real controller writes, physical heating/DHW cycles or long-term display
observations were performed for this release. Field confirmation for #596
and the requested private evidence for #577 remain separate from software
validation. The diagnostic-data collection issue #594 remains open.
