# Release Candidate Evidence: 0.21.3-b4

Status: `BLOCKED` for stable promotion; automated validation passed.

## Scope

Three hardening changes from the #493 self-audit of every sensor-driven
Modbus write path, task cancellation and unload path:

- External power forwarding logs each successful GLT register write at debug
  level (#499). Behavior-neutral; the write cadence becomes visible in
  reporter logs while device-side clearing of RAM inputs remains unconfirmed.
- Room temperature and humidity forwarding no longer cancel a write that is
  already in flight when a source sensor updates (#500). Bursts coalesce into
  follow-up passes reading the latest state, periodic and event-driven passes
  serialize behind a lock, and unload awaits cancelled tasks — the protection
  b1 introduced for external power, ported to the remaining GLT forwarders
  before any user hit the same failure class.
- The comfort schedule and the energy manager finish an in-flight evaluation
  (write, state save or boost start) before their stop path cancels the loop,
  and a deferred web-client session release keeps its task referenced and
  reports failures (#501).

No cooldown, register encoding, controller setpoint or fallback-value policy
changes. No transport, endpoint or dependency change. The older-firmware
battery-display report #493 remains open pending the reporter's retest.
