# Release Candidate Evidence: 0.22.0-b5

Status: `BLOCKED` for stable promotion; automated validation passed. Adds
bidirectional grid-meter support to external power forwarding on top of
0.22.0-b4.

## Scope

- **Bidirectional grid meter for external power forwarding (added, #519):**
  the external power mapping gains a *Bidirectional grid power sensor*
  field with a selectable sign convention (positive = grid import, the
  default, or positive = export). The forwarder normalizes the reading to
  import-positive kW and derives `pv_surplus` (registers 74–75) in the IDM
  convention (positive = export/surplus, negative = grid import); when a
  PV production source is mapped it also derives `house_consumption`
  (registers 82–83) from the site balance, adding mapped battery flow
  (charging negative) and clamping the result at zero. Explicitly mapped
  surplus and house sensors keep precedence, the grid meter alone is never
  written as household consumption, and the mapping dialog rejects a grid
  sensor with nothing left to derive (`grid_power_unused`). The guarded
  register-write path is shared between explicit and derived sources.
  PR #522.

Motivation: feature request #519 (reporter's plant exposes one signed
bidirectional meter sensor; previously required two HA template helpers).
