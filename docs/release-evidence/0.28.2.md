# Release evidence: 0.28.2

The maintainer requested the stable patch on 2026-11-18 to publish the
read-side corrections already merged in PR #722. This is a same-day stable
cut without a seven-day candidate soak. Publication depends on green CI
and Home Assistant smoke tests.

The patch interprets Navigator 10 wall time in the Home Assistant time
zone, continues to probe read-only heating circuit details when circuit A
explicitly reports unavailable, and treats the observed M22 value of
minus one percent as unavailable. The German online-time label changes
without changing the entity ID or its historical units.

The code in PR #722 passed 3,664 local integration tests and 14 real
Home Assistant smoke tests. Regression coverage includes winter and
summer conversion, discovery with missing A and valid pump values.
The minimum Home Assistant version and exact API pin remain unchanged.
The warm-water boost command path is outside this release.

The published ZIP and checksum are checked independently after tagging.
