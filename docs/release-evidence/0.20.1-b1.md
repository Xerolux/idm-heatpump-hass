# Release evidence: 0.20.1-b1

Date: 2026-09-30. Scope: differential-temperature controlled heating circuits,
tracked in [issue #429](https://github.com/Xerolux/idm-heatpump-hass/issues/429).

## Implemented behavior

- Manual, empty-by-default selection in the plant options and advanced form.
- Storage/reference names on the original raw register entity IDs, contextual
  standby status, and reference-minus-storage difference in K in every profile.
- Normal circuit controls, climate, flow deviation and web mixer/flow sensors
  are retired only for selected circuits; the actual web pump remains.
- Registry migration is entry-scoped; switching back restores normal entities.
- No guessed parameter addresses and no additional device writes. Differential
  hysteresis, threshold and maximum temperature remain unverified/unexposed.

## Local quality gates

- Manifest-pinned API and transport: dependency freshness check passed.
- Unit suite: **2,280 passed, 2 skipped**, overall coverage **95.31%**.
- Second full-suite run: **2,280 passed, 2 skipped**, config-flow coverage **100%**.
- Strict mypy against real Home Assistant **2026.8.1**: no issues in 67 modules.
- Ruff lint/format, documentation language and generated translations: passed.
- Real Home Assistant lifecycle suite: **3 passed**, including normal →
  differential → normal reload, frozen entity descriptions, unchanged raw
  temperature IDs, standby state, signed difference, and control restoration.

The unit gates ran from a clean copy of the tracked working tree plus the new
module/test. This excludes local private attachments and ignored deployment
configuration from the repository privacy scan. UTF-8 was explicitly enabled
for the Python/Node KNX-generator parity check on Windows. The repository's
guard remains unchanged; no private values were allowlisted for this release.

## Read-only live compatibility check

- Home Assistant **2026.9.4**, installed integration **0.20.0**, API **2.13.0**,
  modbus-connection **4.12.3**, tmodbus **0.6.2**; config entry loaded.
- The live entry exposed 287 registry entities, 12 disabled. Circuits A and D
  had normal heating controls, with external room temperature forwarding on D.
- A sanitized snapshot of **29 live circuit registers** was captured using
  read-only HA REST/WebSocket requests. No credentials or endpoints are stored
  in this document or release.
- The candidate integration passed a real-HA setup/reload/unload replay of those
  readings: flow/room temperatures and normal room setpoints matched the live
  snapshot, normal climate entities remained, and no differential sensors were
  created with the option off. **1 compatibility test passed.**

This is a live-data compatibility test, not installation of the candidate on
the running plant. The reporter's actual differential circuit is unavailable
on this test plant; physical verification of its measurement labels, standby
interpretation and charging-pump transitions remains outstanding. No plant
setpoints, forwarding settings, KNX configuration or controller options were
changed. The prerelease does not replace the stable Latest release.
