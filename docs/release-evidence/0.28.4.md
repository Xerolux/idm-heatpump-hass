# Release evidence for 0.28.4

On 23 November 2026 the maintainer requested a same-day stable release conditional on successful testing of the candidate on the existing Home Assistant installation.

## Automated checks

The two local unit runs each passed 3,737 tests with two skips. Integration coverage was 98.35% and config flow coverage was 100%. Strict mypy passed for 91 modules. All 15 real Home Assistant lifecycle tests passed on Core 2026.11.0. The device library was the stable PyPI build of 2.17.0.

## Navigator 10 upgrade

The installed candidate replaced 0.28.4-b2 on Home Assistant 2026.11.2. A full backup was copied off the server and its SHA-256 verified. The configuration check passed before restarting Core. After startup the config entry reported loaded, diagnostics confirmed both new runtime versions, and both local transports resumed polling. The registry and published state counts matched the baseline.

The heating circuit A flow target (register 1378) had read status OK. The displayed flow/return difference and instantaneous COP agreed with independent arithmetic. A change in hot water station pump availability matched the controller reporting its documented minus-one-percent sentinel. The B121 temperature matched the controller field and unit. The integration log showed no errors during these checks.

The plant test covered an existing installation in normal operation. First setup, reload and unload were covered by the automated Home Assistant lifecycle suite. DHW restoration and cooldown were exercised with simulated writes. No physical boost, cancellation, other Navigator family or extended soak was tested in this release check.
