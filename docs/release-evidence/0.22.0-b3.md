# Release Candidate Evidence: 0.22.0-b3

Status: `BLOCKED` for stable promotion; automated validation passed. Fixes
Navigator 10 GLT RAM input flicker and bus congestion on top of 0.22.0-b2.

## Scope

- **GLT RAM refresh cadence (fixed, #493):** fallback periodic refresh
  interval reduced from 5.0 s to 3.0 s ($T/2$ of the ~5.0 s controller
  watchdog). Live testing on Navigator 10 (`NAV10_20.23-903`) proved that
  a 5.0 s interval combined with network round-trip time and coordinator
  scheduling jitter caused the hardware watchdog to briefly expire every
  cycle, blinking the battery UI element.
- **Write cooldown cap for external power (fixed, #493):** the coordinator
  write cooldown is capped to 2.0 s specifically for external power
  measurement registers (`battery_soc`, `battery_discharge`, `pv_surplus`,
  `pv_production`). A user-configured general cooldown (default 5.0 s, up to
  600 s) can no longer throttle continuous RAM streaming.
- **Confirmation poll storm suppressed (fixed, #493):** external power
  writes bypass the post-write delayed confirmation full-poll task,
  eliminating a ~2.2 s bus lock on every 3-second cycle.
- **Battery SoC integer rounding (fixed, #493):** `battery_soc` is rounded
  and forwarded as an integer (`int`), stopping thousands of continuous
  `int`-vs-`float` state oscillations in Home Assistant.
- **Informative configuration hint:** the forwarder logs an info line when
  `battery_soc` is mapped without `battery_discharge`, explaining that
  Navigator 10 expects both power and SoC to render the battery card.

Motivation: Live investigation of issue #493 on a real Navigator 10 heat pump
and GoodWe hybrid inverter installation.
