# Release evidence: 0.20.1-b3

Date: 2026-10-01. Scope: Home Assistant 2026.10 compatibility (validated
against the 2026.10.0 beta; the release blog is out, the stable artifact was
not on PyPI at cut time).

## Implemented behavior

- The new `ha_compat` module resolves the schema library and the
  version-moved Home Assistant symbols per generation at runtime and types
  its re-exports as `Any`, so strict mypy passes against both the 2026.8 and
  the 2026.10 annotations. Config flow, services, DHW-boost services,
  repairs and the seven files using the moved enums import through it.
- The CI matrix's forward leg is the 2026.10.0 beta; the declared minimum
  stays 2026.8.1 (matrix leg, release validation and smoke job).
- No user-visible behavior change; no configuration migration.

## Version coverage reasoning

Every mechanism a Home Assistant version between the endpoints can present
is exercised on one of the two validated endpoints:

| Topic | 2026.8.1 (minimum) | 2026.9 | 2026.10.0b0 (forward) |
| --- | --- | --- | --- |
| Schema library | real voluptuous | probatio via HA alias | probatio via HA alias |
| Component enums | from the package | from the package | from `const` |
| `RepairsFlowResult` | present | present | present |

Both branches of every `ha_compat` fallback ran against a genuine Home
Assistant; 2026.9 combines the alias mechanism (validated on 2026.10.0b0)
with the package layout (validated on 2026.8.1).

## Local quality gates

- Unit suite: **2,304 passed, 2 skipped**, overall coverage **95.32 %**
  (gate 95 %). Separate config-flow run: coverage **100 %** (gate 100 %).
- Strict mypy: no issues in 68 modules against real Home Assistant
  **2026.8.1** and against **2026.10.0b0**.
- Real Home Assistant lifecycle suite: **3 passed** on **2026.8.1** and
  **3 passed** on **2026.10.0b0** (setup, reload, unload, entity
  registration, no leaked tasks).
- Dependency freshness (exact API pin, HA-owned transport minimum floors),
  documentation-language and documentation-version checks, sensitive-data
  guard, ruff lint/format: passed.
