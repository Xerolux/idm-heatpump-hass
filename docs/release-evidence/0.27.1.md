# 0.27.1 release evidence

Date: 2026-11-16. Base: stable 0.27.0. API remains pinned to `idm-heatpump-api[web]==2.16.2`; Home Assistant minimum remains 2026.11.0.

## Change and evidence boundaries

Donated telemetry exposed failed Modbus polls without their network causes. This patch adds `network_error_reasons` to the existing local request snapshot, which already reaches the diagnostic sensor attributes and diagnostics export. Counts cover the same last 100 physical requests. They use only exception types and OS error codes through at most eight cause/context links, with cycle detection and suppressed-context handling. No raw messages, endpoints, PINs or donated payloads are published. An allowlist bounds output labels. Existing `outcomes` and exception propagation remain unchanged.

No request, retry, write, entity, telemetry field or consent change is introduced. Unknown causes stay unknown; earlier reports are not retrospectively classified. The reviewed HTTP/statistics payloads already parse under API 2.16.2. No speculative model/register mapping is added and no live heat pump was disconnected or reconfigured for testing.
