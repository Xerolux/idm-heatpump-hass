# Release Candidate Evidence: 0.22.0-b7

Status: `BLOCKED` for stable promotion; automated validation passed. Restores
the advisor room sources step in the guided options walk and documents the
Home Assistant 2026.8+ options entry points on top of 0.22.0-b6.

## Scope

- **Guided advisor room sources step (fixed, #527):** the guided options
  walk never reached the `advisor_room_sources` step for the predictive
  advisor — `_async_complete_guided_feature()`'s `mapping_steps` had no
  entry for it, so after the advisor detail step the flow jumped straight
  to the review and the advisor's room temperature source entities
  (introduced with #504) were unsettable from the UI; only the classic
  options flow offered the step. Fix: the one-line mapping entry
  `"predictive_advisor": "advisor_room_sources"` (the reporter's own
  suggested fix), routing the guided walk into the step, which returns to
  `_async_guided_next()` on submit exactly like the other guided follow-up
  steps; the classic non-guided path is unchanged. Audit confirmed
  `predictive_advisor` was the only feature with a toggle plus optional
  follow-up step missing from `mapping_steps`. Regression test
  `test_predictive_advisor_reaches_advisor_room_sources` pins the whole
  guided sequence. PR #528.
- **Documentation (#526):** the wiki Configuration pages (English and
  German) explain the Home Assistant 2026.8+ entry points — options live
  behind the icon-only gear on the config-entry row, while *Reconfigure*
  is the labeled ⋮ menu item that only re-runs connection setup. Added
  after users repeatedly landed in the reconfigure wizard while looking
  for the options.

Motivation: reporter dnamat88's follow-up #527 to #504 (room sources
unsettable from the UI), plus recurring user confusion about the options
entry point on HA 2026.8+.
