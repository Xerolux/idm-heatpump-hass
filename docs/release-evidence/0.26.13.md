# Release evidence: 0.26.13

Scope: self-explanatory firmware repairs notice (presentation only) and
release-plumbing hardening. Prepared from the maintainer-authorized session on
2026-11-09 that produced the release; the full local gate set was executed in
that session. No submission to IDM Tools, no firmware observation query and no
fresh hardware installation from the ZIP was performed.

## Scope and release decision

- Candidate: `v0.26.13`; API requirement stays `idm-heatpump-api[web]==2.16.2`
  as pinned by 0.26.12; minimum Home Assistant 2026.11.0.
- The repairs notice gains a card-level `description` naming the installed and
  the community-observed version; title, fix flow and acknowledgement behavior
  are unchanged.
- The pin updater now covers the parity-test rejection fixture (`>=` spelling)
  and treats the dated pin comparisons on the Stability page (unchanged-from
  0.26.1 / 0.26.0 / 0.25.0) as history statements: those lines are restored to
  their published versions after the 0.26.11/0.26.12 updater runs had rewritten
  them to the current pin.

## Change under test

| Area | Result | Limit |
|---|---|---|
| Repairs card description | Names `{installed}` and `{observed}` directly on the card, points to *Latest reported firmware* on the Telemetry device | Presentation only; the fix flow, acknowledgement fingerprint and notice lifecycle are untouched |

| Pin updater history guard | Dated Stability-page statements (EN and DE mirrors) restored and protected; the parity-test rejection fixture now follows the pin | Guard patterns are anchored to those sentences; new dated prose must be registered explicitly |

## Interpretation and boundaries

- The richer repairs card is a translation-string change; existing
  acknowledgements, entity IDs, consent state and the notice lifecycle are
  unchanged, and rollback is safe.
- The history-guard hardening affects release tooling only; it changes no
  integration behavior, consent scope or transmitted schema.
- No live plant, no fresh ZIP installation and no IDM Tools traffic were
  involved in preparing this release.
