# Plan 05-01 — Navigator 10 live validation, detection fix, read-only test bench, 0.8.6-beta.2

## Goal

Resolve the Phase-3 MODEL-03/04 evidence-gated checkpoint with real field
evidence, correct the resulting Navigator 10 detection defect found during
validation, and produce a bounded, reproducible `0.8.6-beta.2` release — all
through a strictly read-only Docker test bench that proves no write reached the
heat pump.

## Background

Phase 3 (03-02) left MODEL-03/04 open because no redacted field evidence was
available. This phase obtains that evidence against a live Navigator 10
controller (firmware `NAV10_20.24-880-g265e09c4a`) and acts on it.

## Scope

- Build a local, strictly read-only Docker test bench (Modbus FC01–04 only;
  HTTP GET/HEAD + login POST only; Navigator 10 WebSocket read-commands only)
  that runs Home Assistant with the **local** integration and **local**
  `idm-heatpump-api`.
- Run the isolated API suite and the HA integration against the live device
  through the proxies; verify #170/#171/#172 live; run a 60-minute stability
  test; prove via proxy logs that no write reached the heat pump.

## Requirements covered

- MODEL-03 (evidence-based model correction) — **resolved**: field evidence
  shows the device is Navigator 10, was misdetected as Navigator 2.0.
- MODEL-04 (exact-pinned API release with passing cross-repo contracts) —
  **resolved**: `idm-heatpump-api[web]==0.8.6` with 4 new regression tests;
  cross-repo + release contracts green.
- REL-01/REL-02 (release evidence, reproducibility) — `0.8.6-beta.2` artifacts.

## Tasks

1. Proxies + compose + build/bootstrap/start/stop/clean scripts + README.
2. Isolated API probe (single vs batch, sentinels, Illegal Data Address,
   Nav10 WS login, write-block verification).
3. HA probe (onboarding, entity export, #171 reload regression, stability).
4. Diagnose the live model conflict (Modbus `Navigator 2.0` vs web `NAV 10`).
5. Correct the defect at its root in `idm-heatpump-api` (tertiary indicator).
6. Add regression tests for the corrected detection (live case + Terra-SWM guard).
7. Bump integration to `0.8.6-beta.2`, pin `idm-heatpump-api[web]==0.8.6`,
   sync docs/contract test; build release ZIP + SHA + evidence.

## Verification

- Isolated API live probe: 11/0/0.
- HA integration: 182 entities; Nav10 web supplement via proxy; #171 6/6 services
  after 3 reloads; #172 writable GLT entities created + available at `-1`.
- Stability: 60 min, 120 samples, 0 errors, entity count stable.
- Read-only proof: 5 Modbus FC06 + 3 WS `setting/save` blocks, all synthetic;
  zero writes from HA or the real workflow reached the LAN.
- Automated gate: HASS ruff/mypy/pytest 963; API ruff/mypy/pytest 289.

## Risks / out of scope

- Other Navigator models not available on the bench (covered by unit fakes).
- 4108 standby decode (`leistungsbegrenzung_*` unavailable) — deferred.
- `hide_unused_registers` long-term simplification — deferred to next milestone.
