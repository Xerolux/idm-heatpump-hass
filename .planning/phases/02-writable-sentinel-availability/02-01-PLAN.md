<objective>
Let writable control entities (Number/Select/Switch) be created at setup even when their current
value is an unset sentinel, while keeping read-only sensors and genuinely absent/unsupported
registers filtered out (GitHub issue #172 creation gate; part of #170).

Purpose: With `hide_unused_registers` enabled, the generic unused/sentinel filter currently
drops writable GLT/PV inputs together with read-only noise. External inputs must remain
addressable precisely when they are unset. Output: a narrow, explicit writable-control creation
mode that never exposes a register that is absent, model-excluded, or Illegal-Data-Address.
</objective>
